ARTIXO Effect portable mode

While this file sits next to artixo-effect.exe, ARTIXO Effect keeps its settings, keyboard shortcuts,
crash-recovery files, logs and plug-ins in the ArtixoEffectData folder beside it instead of
%APPDATA%\ARTIXO Effect. Copy the whole folder to move ARTIXO Effect with its settings.

The disk cache, media cache and conformed audio still go to %LOCALAPPDATA%\ARTIXO Effect unless
you choose other folders in Edit > Preferences > Disk.

Delete this file to use the normal per-user settings folder (%APPDATA%\ARTIXO Effect) instead.
If ArtixoEffectData can't be written (for example on a read-only drive), ARTIXO Effect logs a
warning and uses %APPDATA%\ARTIXO Effect instead.
