# ARTIXO Effect app icon

**Artwork:** the ARTIXO logo, an engraved ape wearing cameras and carrying a camera rig, on a
full-bleed pink tile.

**Tile:** 1024 x 1024 source with rounded corners keyed to transparency.

**Provenance:** supplied by the project owner (ARTIXO ONE). The SVG files wrap the PNG raster; they
are not vector-traced. Licence: see [LICENSE.txt](LICENSE.txt) and `docs/brand/LICENSE-brand.txt`.

## Files

| File | What |
|---|---|
| `artixo-effect.svg` | master (1024 px raster wrapped in SVG) |
| `artixo-effect-small.svg` | lighter wrapper (512 px); the web favicon uses a 256 px one |
| `artixo-effect-1024.png` | 1024 px render |
| `artixo-effect-macos-512.png` | runtime Dock icon on macOS, on Apple's 824/1024 grid |
| `artixo-effect.icns` | macOS app icon |
| `artixo-effect.ico` | Windows app icon (16-256 px) |
| `hicolor/<n>x<n>/apps/com.artixoone.effect.png` | Linux icon theme, 16-512 px; the 256 px one is the runtime icon on Windows and Linux |
| `hicolor/scalable/apps/com.artixoone.effect.svg` | Linux scalable icon |

App ID: `com.artixoone.effect` (Wayland app ID, `packaging/linux/com.artixoone.effect.desktop`).
